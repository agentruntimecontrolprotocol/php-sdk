## Exception hierarchy violations (PHP_SDK_GUIDE.md §5)

### Direct throws of SPL exceptions in library code

```

```

### Root marker shape mismatch

- `Arcp\Errors\ARCPException` is an **abstract class** extending
  `\RuntimeException`. Guide §5 wants an **interface** extending
  `\Throwable` so consumers can catch one type and concrete exceptions
  can extend any SPL parent (or none) appropriate to their nature.
